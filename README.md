# C Playground

Este repositório reúne os exercícios e pequenos projetos que estou desenvolvendo enquanto aprendo linguagem C na disciplina de Programação I.

## Conteúdos

- Estrutura básica de um programa em C
- Variáveis e tipos de dados
- Entrada e saída de dados
- Operadores aritméticos
- Expressões condicionais
- Estruturas de repetição
- Vetores, matrizes e funções

## Organização

Os códigos estão organizados por aula e cada arquivo `.c` representa um exercício independente.
